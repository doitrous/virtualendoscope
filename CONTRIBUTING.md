# Contributing

Thank you for helping improve Virtual Endoscope.

## Before opening a change

1. Create a focused branch from `main`.
2. Run `npm ci` and `npm test`.
3. Test visual or interaction changes in a current desktop browser.
4. Keep clinical claims sourced and clearly label approximations.
5. Do not commit patient-identifiable data or media without documented reuse permission.

## Pull requests

Describe what changed, why it helps learners, how it was tested, and any clinical or performance limitations. Include screenshots or short recordings for visible changes when licensing permits.

Changes to anatomy, disease appearance, physiology or teaching language should include an authoritative reference and ideally review from a suitably qualified clinician or educator. Passing automated tests does not constitute clinical validation.

## Media contributions

Only contribute media that you created or are authorized to redistribute publicly. Record the creator, source URL, license and required attribution. By contributing original code, you agree that it may be distributed under the repository's MIT License. Third-party media retain their own terms.
